Static demo, not the live app. Everything below is real - the ten sample clips/photos, the AI-generated edit plan and its reasoning, the per-clip color numbers, and the rendered video - but nothing here is running: this page doesn't call ffmpeg or the Claude API. The actual app needs ffmpeg and your own Anthropic API key, so it only runs locally - see the source on GitHub to run it yourself.
