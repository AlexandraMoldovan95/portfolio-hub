Desktop Buddy

A Windows companion that records only the app you are testing, starts and stops by itself, and turns the run into short MP4 clips.

Live demo View on GitHub

What it does

Desktop app (Electron, vanilla JS) with an animated buddy that grows with your focus time. It records one app window by its title, joins relaunches into one file, lets you mark good moments with one click, and cuts clips or a short movie without ffmpeg. Also: a focus timer with statistics, notes with reminders, a clipboard history that never saves secrets, and screenshots you can draw on. Works offline. Playable in the browser.

My role

Product idea, UX and visual design, feature specs, QA (72 test cases, a defect log), and three audit rounds. The code was written in pair-programming with an AI assistant (Claude).

Quality

295 unit tests · ESLint + CI on Windows · 72 test cases passed (48 run by hand on Windows, 24 automated), with a defect log · ~145 audit findings fixed.

Status

Why this exists

I needed a way to capture clean recordings while testing an app - without manually starting and stopping a recorder, and without ending up with one giant unusable video per session. The buddy itself (an on-screen companion that reacts to focus time) came out of wanting the tool to be something I'd actually enjoy keeping open all day, not just a background utility.

Highlights

  • Window-targeted recording. Captures a single app window by its title and joins relaunches of the same app into one continuous file, instead of leaving you with a folder of fragments.
  • A clipboard history that's deliberately safe. Keeps recent clipboard entries for convenience, with logic in place to never save anything that looks like a secret.
  • Clip cutting without a separate video editor. Flag a good moment during a recording, then cut clips or a short highlight movie afterward - using the browser's own built-in media tools (MediaRecorder + canvas) instead of bundling an external video-encoding program (ffmpeg).
  • Testable by design. The app's decision-making logic is kept separate from the on-screen app itself, in plain, framework-free modules, so each piece can be checked automatically - 295 unit tests - instead of only by clicking around by hand.
  • Locked down, not just functional. Each window runs in a restricted sandbox that can't reach your files directly, messages between app parts are checked before being trusted, and stored secrets are encrypted - what engineers call sandboxing, a Content Security Policy (CSP), and verified IPC (inter-process communication) channels. Security review was part of all three audit rounds, not an afterthought.

How it was built

Electron on top of vanilla JavaScript - no UI framework. The app logic (scheduling, clip-cutting rules, the buddy's state machine) is written as pure, side-effect-free modules so it can be unit tested without spinning up Electron itself; the Electron layer is a thin shell around it. Media capture uses the browser's native MediaRecorder and canvas APIs rather than a bundled ffmpeg binary, which keeps the install small. Quality was treated as a first-class part of the build: a written test plan, a defect log, and three full audit passes before calling any version done.
